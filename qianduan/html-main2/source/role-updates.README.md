# 岗位变化观察台（本次新增）

这个文件夹是本次新增的前端展示预览，专门对应两类变化：

- **新岗位涌现**：展示“新增岗位”和“新兴细分”。
- **旧岗位能力更新**：展示“新增能力”“能力增强”“能力减少”。

## 打开方式

直接双击 `index.html` 即可预览，不依赖 Neo4j、后端服务或数据文件。也可以把整个文件夹交给队员做风格参考。

## 新增内容标记

- 顶部“本次新增”标记：说明这是独立新增页面，不替换现有页面。
- 绿色 `新增岗位` / `新增能力`：当前观察周期出现、基线周期不存在。
- 蓝色 `能力增强`：已有能力的招聘覆盖率上升。
- 橙色 `能力减少`：已有能力的招聘覆盖率下降，保留用于复核。

页面中的岗位名称、数量和变化百分比是脱敏示例，只用于统一视觉。接入真实接口时，保留页面结构和标签语义，替换 `index.html` 里的示例数组即可；不需要改后端处理逻辑。
