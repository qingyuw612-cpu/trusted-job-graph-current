# Background Assets

Source repository: https://github.com/sschoger/hero-patterns
Project site and license: https://heropatterns.com/ · CC BY 4.0

Files used:

- `topography.svg`
- `circuit-board.svg`

They are used as subtle local UI textures for the unified frontend background and header.
